## 🚀 Features

- 👤 **Multi-Role Dashboard**: Tailored experiences for **Admin**, **Teacher**, and **Student**.
- 📱 **QR Code Attendance**: Scan-to-attend for fast and secure student check-ins.
- 📊 **Real-time Analytics**: Automated reporting and daily attendance summaries.
- 📋 **Management Suite**: Comprehensive tools for managing Students, Classes, Subjects, and Schedules.
- 🔔 **Instant Notifications**: Stay updated with important school announcements.

## 🏁 Getting Started

Follow these steps to get your development environment up and running:

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [Go](https://golang.org/) (v1.20+)
- [MySQL](https://www.mysql.com/)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/aa-bayu2007/dfy_school.git

# Install dependencies
npm install
```

### 3. Setup & Run
Check out our [Setup Guide](./SETUP_GUIDE.md) for detailed configuration.

```bash
# Setup database
# (Update your .env files in backend and frontend)

# Run Backend
npm run backend

# Run Frontend
npm run dev
```
